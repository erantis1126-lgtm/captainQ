# 캪틴큐 레이더

내 주변의 캪틴큐 판매 체인 매장(CU · GS25 · 세븐일레븐 · 이마트24 · 이마트 · 롯데마트 · 롯데슈퍼)을 거리순으로 보여 주는 모바일 웹페이지입니다.

- 현재 위치(GPS) 또는 동·역 이름으로 검색, 반경 1km / 3km / 5km
- 매장별 `재고 확인` → 검색어 `캪틴큐`(ㅍ받침) 복사 후 각 편의점 앱(포켓CU · 우리동네GS · 세븐앱 · 이마트24)으로 연결
- 카카오맵 길찾기, 전화 / 네이버 지도 매장정보
- `있었어요 / 없었어요` 메모 (이 기기의 브라우저에만 저장)

## 참고

- 재고 수량은 이 페이지가 직접 조회하지 않습니다. 실제 재고는 각 편의점 앱에서 확인하세요.
- 매장 목록은 OpenStreetMap(Overpass API) 데이터라 빠진 매장이 있을 수 있습니다. 위치 검색은 Nominatim을 사용합니다.
- GPS는 https 주소(GitHub Pages 등)에서만 동작합니다.
